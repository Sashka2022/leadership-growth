# Project guidance

This is a buildless Hebrew RTL static application. Serve dist/ with a static HTTP server. No dependency installation is required.

Preserve the six-stage educational journey and existing localStorage key leadership-growth-v1. If changing the state schema, migrate existing data and preserve JSON backup compatibility.

Keep private reflection fields out of plan downloads and printed decision cards. No telemetry or remote transmission of answers is currently implemented. Keep that behavior unless the user explicitly requests a change.

Maintain accessible labels, keyboard focus, mobile layout, high contrast and large text preferences. All user-entered content inserted into HTML must be escaped.

Run `node --check dist/app.js` and `node checks.mjs` after logic changes. Review the rendered UI for layout changes. Publish only through the user's selected destination; this portable copy does not contain the original hosting identity.
