# מרחב לצמוח

אפליקציית למידה בעברית למנהלות: שש תחנות מהתבוננות במקרה ניהולי ועד כרטיס החלטה מעשי.

## הפעלה מקומית

אין ספריות להתקנה ואין צורך במפתח API.

```bash
python3 -m http.server 8000 --directory dist
```

פתחו בדפדפן: http://localhost:8000

ב-Windows אפשר להשתמש בפקודה `py -m http.server 8000 --directory dist`.

## בדיקות

נדרש Node.js 20 ומעלה:

```bash
node --check dist/app.js
node checks.mjs
```

## פתיחה ב-Codex

1. חלצו את החבילה לתיקייה.
2. פתחו את התיקייה כפרויקט ב-Codex המקומי, או העלו ל-GitHub ובחרו את המאגר ב-Codex המחובר ל-GitHub.
3. בקשו למשל: ״קרא את README.md ואת AGENTS.md, הפעל את הפרויקט והמשך לפתח את האפליקציה תוך שמירת התוכן והתשובות הקיימות״.

## העלאה ל-GitHub

צרו מאגר חדש וריק בחשבון שלכם. העלו אליו את תוכן התיקייה המחולצת, כולל dist, README.md, AGENTS.md, checks.mjs ותיקיית .github.

אפשר להעלות דרך הממשק Add file → Upload files. העלו את הקבצים והתיקיות המחולצים, ולא את קובץ ה-ZIP עצמו. אם תיקיית .github אינה מוצגת במחשב, השתמשו ב-Git או צרו את קובץ ה-workflow דרך ממשק GitHub.

אפשר גם להעלות דרך Git, מתוך תיקיית הפרויקט:

```bash
git init
git add .
git commit -m "Initial leadership learning app"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

החליפו את YOUR_GITHUB_REPOSITORY_URL בכתובת המאגר החדש שלכם.

## פרסום דרך GitHub Pages

בחבילה קיים workflow לפרסום תוכן dist ב-GitHub Pages.

1. במאגר פתחו Settings → Pages.
2. בחרו GitHub Actions כמקור הפרסום, אם האפשרות זמינה בחשבון ובמאגר.
3. פתחו Actions והפעילו את Deploy static site, או דחפו שינוי לענף main.
4. לאחר הצלחת הפעולה, כתובת האתר תופיע בפריסת GitHub Pages.

הפרסום דורש ש-GitHub Actions ו-Pages יהיו מופעלים ומורשים במאגר. אין צורך בשירותי האירוח המקוריים של האפליקציה.

## מבנה

- dist/index.html — מעטפת האפליקציה.
- dist/style.css — עיצוב RTL, התאמה למסכים קטנים, הדפסה ונגישות.
- dist/app.js — שלבי העבודה, שדות, שמירה מקומית, שעון, ייצוא וייבוא.
- checks.mjs — בדיקות שחזור נתונים והפרדת מידע אישי מכרטיס ההחלטה.
- .github/workflows/pages.yml — פרסום האתר הסטטי.

## שמירת נתונים

התשובות נשמרות ב-localStorage של הדפדפן תחת המפתח leadership-growth-v1. אין שרת נתונים ואין שליחת תשובות למנחה. גיבוי JSON כולל את כל המחברת; כרטיס ההחלטה כולל רק את שדות ההחלטה.

מעבר לכתובת אתר אחרת אינו מעביר את התשובות אוטומטית. יש להוריד גיבוי מהאתר הקיים ולטעון אותו באתר החדש דרך הגדרות המחברת.

## היקף החבילה

זהו קוד המקור של הגרסה שנבנתה בשיחה. החבילה אינה כוללת נתוני משתמשות, היסטוריית Git, מפתחות גישה או הגדרות חשבון של שירות האירוח המקורי. העלאה למאגר אחר לא משנה אוטומטית את האתר הקיים.
